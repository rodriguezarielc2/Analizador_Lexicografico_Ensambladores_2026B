# Entradas de demostración de Fase 1

1. `01_basico.ens`: segmentos, etiquetas, separadores, comentarios, registros y constantes.
2. `02_compuestos_y_constantes.ens`: formas válidas de compuestos, literales y las tres bases numéricas.
3. `03_equipo2.ens`: las veinte instrucciones del Equipo 2. `MOV`, `ADD` y `RET` deben aparecer como símbolos.
4. `04_elementos_invalidos.ens`: errores intencionales en nombres, constantes, comillas, referencias y compuestos. Se espera que existan elementos inválidos.
5. `05_paginacion.ens`: entrada extensa para revisar navegación y numeración continua.

Los ejemplos 1, 2, 3 y 5 usan elementos léxicamente válidos conforme a las reglas documentadas en el README principal. Esto no afirma que los programas sean correctos en los análisis sintáctico o semántico. Por ejemplo, un mnemónico no asignado puede aparecer como símbolo.

La plantilla original de clase permanece en `verificacion/tests/Plantilla.ens`, con sus errores intencionales. La referencia normativa es Moodle, las aclaraciones docentes y la presentación proporcionada; los programas no necesitan ejecutarse en un emulador.
